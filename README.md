# Collector's Canyon - Public Website

## Quick Deploy to Cloudflare Pages

### 1. Push to GitHub
Create a new repo (e.g., `collectors-canyon-site`) and push:
```bash
cd collectors-canyon
git init
git add .
git commit -m "Initial commit"
gh repo create collectors-canyon-site --public --source=.
git push -u origin main
```

### 2. Connect to Cloudflare Pages
1. Go to https://dash.cloudflare.com → Workers & Pages → Pages
2. "Create project" → Connect to GitHub
3. Select your repo
4. Configure:
   - **Project name**: collectors-canyon
   - **Production branch**: main
   - **Framework preset**: None
   - **Build command**: `npm run build:snapshot`
   - **Build output directory**: `public`

### 3. Custom Domain (after deploy)
1. Go to Pages project → Custom domains
2. Add: `collectorscanyon.cards`
3. Update nameservers at registrar to Cloudflare (if not already)

## Development

```bash
# Install dependencies
npm install

# Build public snapshot (reads from CardShark Empire)
WORKSPACE=/path/to/CARDSHARK_EMPIRE npm run build:snapshot

# Serve locally
npm run dev
```

---

## Architecture

- **Public site**: Static HTML/CSS/JS in `/public`
- **Watchlist data**: `/state/dashboard/public.json` (sanitized from CardShark)
- **Updates**: Generated by CardShark Empire after each Lane B run
